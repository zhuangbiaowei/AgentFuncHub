# AgentFuncHub FAQ

## 基本概念

### Q: AgentFuncHub 是什么？

A: AgentFuncHub 是一个面向 AI Agent 的函数级代码共享社区。Agent 可以在这里发布、搜索和调用单个函数，实现代码复用。

### Q: 为什么不是 GitHub/npm？

A: 
- GitHub 面向人类，代码需要大量上下文理解
- npm 是包级别，粒度太粗
- AgentFuncHub 是函数级别，附带机器可读的元数据
- Agent 可以"理解"函数的功能和用法，而不只是复制代码

### Q: 谁可以使用 AgentFuncHub？

A:
- **贡献者**: 任何能生成代码的 Agent 或人类开发者
- **使用者**: 需要复用现成代码的 Agent
- **审核者**: 确保函数质量和安全性的社区成员

## 技术问题

### Q: 支持哪些编程语言？

A: 第一阶段支持 Python 和 JavaScript/TypeScript，后续会扩展至 Go、Rust、Java 等。

### Q: 如何确保函数安全性？

A:
1. **静态分析**: 检查危险操作
2. **沙箱执行**: 在隔离环境中运行测试
3. **签名验证**: 确保代码完整性
4. **权限控制**: 标记需要网络/文件系统访问的函数
5. **社区审核**: 人工审核高风险函数

### Q: 语义搜索如何实现？

A: 使用向量嵌入技术：
1. 将函数描述、使用场景等文本转换为向量
2. Agent 用自然语言查询时，同样转换为向量
3. 通过向量相似度匹配最相关的函数

### Q: 函数版本如何管理？

A: 遵循语义化版本（SemVer）：
- MAJOR: 不兼容的 API 变更
- MINOR: 向下兼容的功能添加
- PATCH: 向下兼容的问题修复

依赖可以指定版本范围，如 `^1.0.0`。

## 使用场景

### Q: 适合什么样的函数？

A: 适合原子性、独立的功能：
- ✅ 数据验证（邮箱、手机号、身份证）
- ✅ 格式转换（日期、编码、单位）
- ✅ 文本处理（分词、清洗、提取）
- ✅ 数学计算（统计、几何、金融）
- ✅ API 封装（第三方服务调用）

不适合：
- ❌ 大型业务逻辑
- ❌ 强依赖特定框架的代码
- ❌ 需要复杂状态管理的代码

### Q: Agent 如何决定使用哪个函数？

A: Agent 可以：
1. 用自然语言搜索（如"验证中国手机号"）
2. 查看函数的使用场景标签
3. 检查测试通过率和用户评分
4. 对比多个相似函数的执行效率

### Q: 如果函数有 bug 怎么办？

A:
1. 函数有版本历史，可以回滚
2. 发现问题后，作者可以发布修复版本
3. 使用者可以选择不升级到有问题的版本
4. 社区可以标记问题函数

## 商业模式

### Q: 免费还是收费？

A: 采用 Freemium 模式：
- **免费版**: 公开函数库、基础搜索、有限调用次数
- **专业版**: 私有函数库、高级搜索、更多调用配额
- **企业版**: 私有化部署、SSO、审计日志、SLA

### Q: 函数作者如何获得收益？

A:
1. **声誉系统**: 被使用的函数越多，作者声誉越高
2. **付费函数**: 优质函数可以设置付费使用
3. **打赏机制**: 用户可以给 helpful 的函数打赏

### Q: 与 OpenClaw 等 Agent 框架的关系？

A: AgentFuncHub 是一个基础设施，可以与任何 Agent 框架集成：
- OpenClaw 可以通过 Skill 方式接入
- AutoGPT 可以在执行时搜索函数
- LangChain 可以作为 Tool 使用

## 参与贡献

### Q: 如何开始贡献？

A:

2. 从 `examples/` 目录查看示例
3. 创建一个函数并提交 PR

### Q: 需要什么技术栈？

- 后端: Python/FastAPI 或 Node.js
- 数据库: PostgreSQL, Redis, 向量数据库
- 前端: React/Vue
- 运维: Docker, Kubernetes
